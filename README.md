# Market Stress Dashboard

Static Market Stress Dashboard powered by `data.json`.

## Daily Publishing Setup

1. Go to Settings → Secrets and variables → Actions.
2. Add a repository secret named `OPENAI_API_KEY`.
3. Run the "Daily Market Stress Dashboard" workflow manually once from the Actions tab.
4. Confirm `data.json`, `history/YYYY-MM-DD.json`, and `history/index.json` update correctly.
